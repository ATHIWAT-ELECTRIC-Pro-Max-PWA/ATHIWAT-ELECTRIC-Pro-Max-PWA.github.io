# ATHIWAT ELECTRIC Pro Max — คู่มือเตรียมสอบครูผู้ช่วยอาชีวศึกษา

เว็บแอปนี้เชื่อม Supabase project `athiwat-electric-exam` แล้ว ใช้ Supabase Auth สำหรับสมัคร/เข้าสู่ระบบ และบันทึกคลังข้อสอบ ผลสอบ โควตาฟรี และวิเคราะห์จุดอ่อนบนฐานข้อมูลเดียวกัน

## ใช้งาน

1. เว็บไซต์เผยแพร่แล้วบน GitHub Pages ที่ <https://athiwat-electric-pro-max-pwa.github.io/> และใช้ HTTPS
2. เปิดเว็บไซต์เพื่อสมัครสมาชิก/เข้าสู่ระบบ และติดตั้งเป็น PWA บนมือถือได้ (การเปิดไฟล์ตรงเหมาะกับดูหน้าตาและโหมดสาธิต)
3. สมัครด้วยอีเมลและรหัสผ่าน หรือเข้าสู่ระบบด้วยบัญชีเดิม หากเปิดยืนยันอีเมล ให้กดยืนยันจากอีเมลก่อน
4. สมัครบัญชีของเจ้าของระบบเป็นบัญชีแรกก่อนแชร์ลิงก์ให้ผู้อื่น เพราะบัญชีแรกจะได้รับสิทธิ์ผู้ดูแลคลังข้อสอบโดยอัตโนมัติ จากนั้นเพิ่มข้อสอบทีละข้อที่เมนู “คลังข้อสอบ” หรือใช้เมนู “นำเข้าไฟล์” เพื่อนำเข้าจาก `.docx`/`.pdf`
5. สมาชิกฟรีเข้าถึงข้อสอบพื้นฐานและทำได้ไม่เกิน 10 ข้อต่อวัน ส่วน Pro Max ต้องกำหนดสิทธิ์ในฐานข้อมูล
6. ผลสอบและ Analytics ซิงก์ข้ามอุปกรณ์ที่เข้าสู่ระบบบัญชีเดียวกัน ระบบ lease อนุญาตให้บัญชีใช้งานพร้อมกันได้หนึ่งอุปกรณ์

## ฟังก์ชันที่เชื่อมแล้ว

- สมัครและเข้าสู่ระบบด้วย Supabase Auth; ไม่เก็บรหัสผ่านไว้ในแอป
- โหลดเฉพาะข้อสอบที่เผยแพร่และสมาชิกมีสิทธิ์เข้าถึง โดยไม่ส่ง answer key มากับรายการข้อสอบ
- Practice ตรวจคำตอบผ่าน RPC และ Mock สลับลำดับตัวเลือก/ข้อสอบก่อนส่งคะแนน
- บันทึก attempt/answers ใน Supabase, แสดง Key Point ตามสิทธิ์ และวิเคราะห์จุดอ่อนราย Topic
- เพิ่ม/ลบข้อสอบออนไลน์ได้เฉพาะผู้ดูแลเนื้อหา
- ผู้ดูแลนำเข้าข้อสอบหลายข้อจากไฟล์ Word/PDF ได้ ตรวจตัวอย่างและข้อผิดพลาดก่อนบันทึก พร้อมกำหนดประเภทสอบ ภาค หมวดวิชา Topic และระดับสิทธิ์
- ใช้โลโก้ ATHIWAT ELECTRIC ในแถบแบรนด์ ไอคอนเว็บ และไอคอน PWA บนมือถือ
- service worker แคชเฉพาะไฟล์เว็บในโดเมนเดียวกัน และไม่แคชคำขอ Supabase

## นำเข้าข้อสอบจากเอกสาร

1. เข้าระบบด้วยบัญชีผู้ดูแลคลัง แล้วเปิดเมนู “นำเข้าไฟล์”
2. กำหนดค่าเริ่มต้นของประเภทสอบ ภาค หมวดวิชา Topic และสิทธิ์ หรือใส่ tag แยกเป็นรายข้อในเอกสาร
3. เลือก `.docx` หรือ `.pdf` ที่มีข้อความเลือก/คัดลอกได้ (PDF สแกนภาพยังไม่รองรับ OCR)
4. ตรวจตัวอย่าง ทุกข้อจำเป็นต้องมีโจทย์ ตัวเลือกครบ 4 ข้อ คำตอบ หมวดวิชา และ Topic ก่อนนำเข้า
5. กด “นำเข้า” เพื่อบันทึกข้อสอบที่เผยแพร่เข้าคลังออนไลน์ สมาชิกจะเห็นตามระดับสิทธิ์และแพ็กเกจ

ใช้แม่แบบ `supabase/question-import-template.txt` โดยใส่โจทย์ขึ้นต้น `ข้อ 1.` และแยกตัวเลือก `ก.` `ข.` `ค.` `ง.` คนละบรรทัด ระบุ `Topic:`, `คำตอบ:`, `เฉลย:` และ `Key Point:` ได้ ไฟล์ต้องไม่เกิน 20 MB และ PDF ไม่เกิน 100 หน้า

ระบบอ่านเนื้อหาเอกสารในเบราว์เซอร์ ไฟล์ต้นฉบับไม่ถูกอัปโหลดไปเก็บ แต่ข้อมูลข้อสอบจะถูกส่งไป Supabase เมื่อผู้ดูแลกดนำเข้า

## แพ็กเกจ Pro Max และการชำระเงิน

แพ็กเกจที่เตรียมไว้คือชำระครั้งเดียว **199 บาท ใช้ได้ตลอดชีพ** ไม่มีค่าต่ออายุรายเดือนหรือรายปี หน้าเว็บใช้ Stripe Checkout สำหรับบัตรและ PromptPay (ถ้าเปิดให้บัญชี Stripe) และเปิดสิทธิ์จาก webhook ที่ตรวจลายเซ็นและยอดชำระแล้วเท่านั้น

โค้ดและฐานข้อมูลเตรียมไว้แล้ว แต่จะรับเงินจริงได้หลังเจ้าของบัญชีเปิดบัญชี Stripe ในประเทศไทยและตั้งค่าความลับ/ปลายทาง webhook ตาม `supabase/README_TH.md` เท่านั้น **อย่าใส่ Stripe Secret key หรือ Supabase service-role key ในเว็บ ไฟล์สาธารณะ หรือแชต**

## PWA และขอบเขตมือถือ

โฮสต์โฟลเดอร์นี้บน HTTPS แล้วจึงติดตั้งเป็น PWA บน iOS/Android ได้ ความคืบหน้าซิงก์ผ่าน Supabase; PWA ไม่สามารถบล็อกภาพหน้าจอหรือรับประกันล็อกอุปกรณ์ได้เหมือนแอป Native การเผยแพร่ Store และการบล็อกภาพหน้าจอต้องเพิ่มตัวแอป Native และ backend policy เพิ่มเติม

## ฐานข้อมูล

- โครงสร้างเต็มอยู่ที่ `supabase/schema.sql`
- การเพิ่มวันหมดอายุและรับชำระ Stripe อยู่ที่ `supabase/billing-migration.sql`
- Supabase Edge Functions อยู่ที่ `supabase/functions/` และการตั้งค่า JWT อยู่ที่ `supabase/config.toml`
- ฟังก์ชันตั้งผู้ดูแลคนแรกอยู่ที่ `supabase/cloud-app-migration.sql` (ติดตั้งแล้วในโปรเจ็กต์นี้)
- ขั้นตอนสำหรับโปรเจ็กต์ Supabase ใหม่อยู่ใน `supabase/README_TH.md`
- `supabase-config.js` มี Project URL กับ Publishable key สำหรับเว็บเท่านั้น ห้ามใส่ Secret/service-role key

ข้อสอบตัวอย่างเป็นเนื้อหาสาธิต โปรดตรวจความถูกต้องและประกาศรับสมัครฉบับล่าสุดก่อนนำไปใช้จริง
